# SLC-AQI-Predictions-Project

This model is set up to predict the AQI for today and the next 4 days. 

Due to the nature of making predictions in real time, some data files need to be updated manually prior to running the models. 

An html file with the printout of the predictions run on December 4th, 2016 was included for refrence on how everything should look when updated properly. 

Additionally, snapshot of the website from which we obtained weather data and a sample document that is retreived from it was included as reference.
